# YouTube Homepage — UI/UX Improvement Prototype

Prototype redesign halaman beranda YouTube untuk tugas evaluasi UI/UX.

## Fitur prototype
- Layout homepage bertema dark mode.
- Header dengan search bar.
- Sidebar navigasi yang dapat diciutkan.
- Filter kategori video.
- Pencarian berdasarkan judul, channel, dan kategori.
- Grid video responsif.
- Toast feedback untuk tombol-tombol simulasi.
- Tampilan adaptif untuk desktop, tablet, dan smartphone.

## Struktur
- `index.html` — struktur halaman.
- `style.css` — desain dan responsive layout.
- `script.js` — data contoh dan interaksi.

## Catatan
Ini adalah prototype pembelajaran, bukan aplikasi YouTube resmi. Data video dan beberapa interaksi bersifat simulasi. Gambar thumbnail diambil dari Unsplash sehingga memerlukan koneksi internet. Logo dan nama YouTube digunakan hanya untuk konteks evaluasi antarmuka.
